# 데이터 이용 조건

이 저장소의 프로그램 코드는 MIT 라이선스입니다. 데이터는 자동으로 MIT로
재허가되지 않으며, 각 원자료의 권리 조건을 따릅니다.

공개 번들에 포함할 수 있는 위치 근거는 상업 이용·수정·재배포를 허용하는
공공누리 1유형, CC0, 퍼블릭 도메인, CC BY 계열로 제한합니다. 비영리 전용,
변경 금지, 이용조건 불명 자료는 `license_blocked` 또는 `review_required`로
남기고 지도에 노출하지 않습니다.

과거 데이터는 [공공데이터포털의 한국학중앙연구원 조선조문과급제자 데이터](https://www.data.go.kr/data/15052752/fileData.do)를
원자료로 사용합니다. 해당 공식 페이지의 이용허락범위가 “제한 없음”인지 확인하고,
한국학중앙연구원과 공공데이터포털을 귀속합니다. 웹 백과사전의 이미지나 원문은
복제하지 않습니다.

지도 타일은 [OpenStreetMap 저작권](https://www.openstreetmap.org/copyright)과
[타일 정책](https://operations.osmfoundation.org/policies/tiles/)을 따르며,
타일 제공자 약관에 따라 `NEXT_PUBLIC_MAP_TILE_URL`을 설정해야 합니다.
